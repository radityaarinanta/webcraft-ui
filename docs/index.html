Vanilla Web Architecture

High-performance UI components with zero dependencies.

WebCraft UI provides accessible, modular, and lightweight interface primitives built with standard HTML5, CSS3, and JavaScript.

Toast Notifications

Floating temporary alerts with auto-dismiss and status variants.

import { Toast } from './src/index.js';

Toast.show({
  type: 'success',
  title: 'Changes Saved',
  message: 'Your project configurations have been updated successfully.',
  duration: 4000
});
